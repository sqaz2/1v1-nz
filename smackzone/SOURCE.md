# Smackzone

Port of sqaz2/StarMuff's original Smackzone, Asteroid Keno, Companion Racing,
ship sprite, creature definitions and music. Baseline: 83338c74afeba259c704062bac7e8638de7bfb98.
The source lives under `smackzone/src`; `node smackzone/build.mjs` builds the native arcade page.
Original media is served by the existing StarMuff Pages asset mirror.
`style.css` is generated by StarMuff's Tailwind 4 bridge build and includes these components.

Quantum Chips are free arcade points stored on this browser and origin. The old
pilot ID, shard APIs, global raffle and space-game credits are not used. Cloud
account linking and a server-validated shared wallet are future work. This page
is solo play; it does not claim to be a head-to-head casino.

Unwritten Skies uses the same wallet interface, with acknowledgement through its
existing authenticated flight-save checkpoint queue. No legacy balances are migrated.
Update the vendored components and generated CSS together when porting future fixes.
