# Bomb Man character art — v2

These references were generated with the built-in image generation tool from the game's existing hero, robot and menu artwork. They guide the real-time geometry in `../characters3d.mjs`; characters are modeled parts with animated limbs, not image billboards.

- [Hero turnaround](hero-turnaround-v2.webp): aviator cap, blue goggles, cream cheeks, red scarf, blue suit, leather gloves and boots, star belt.
- [Robot turnaround](robot-turnaround-v2.webp): beveled silver head, black face, red eyes and antenna, armored joints.

The source PNGs were optimized to WebP for this repository. The existing tile, crate, metal, pickup and arena background collection is also used by the renderer.

## Hero prompt

Use case: stylized-concept. Asset type: Bomberman game character design reference and player portrait. Using the supplied existing game art as identity/style references, create a polished 3D character turnaround sheet of the SAME orange-and-cream hamster aviator hero. Leather aviator cap, brass goggles with blue lenses worn above eyes, big expressive black eyes, cream cheek puffs and muzzle, tiny pink nose, two little teeth, red scarf, rich blue jumpsuit with gold cuffs, brown gloves and boots, leather utility belt with gold star buckle and pouches. Stylized collectible game character, appealing and highly dimensional, visibly modeled materials, clean readable shapes, no flat pixel art. Three full-body views side by side on dark navy studio background: front three-quarter hero pose largest at left holding a small black bomb, neutral side and back smaller at right. Entire ears and feet visible with margin. Match reference colors, costume and proportions closely. Soft cinematic warm key light, cool rim, subtle floor shadow. No text, no labels, no watermark. This will guide actual animated 3D mesh modeling in a browser game.

## Robot prompt

Use case: stylized-concept. Asset type: Bomberman enemy 3D character reference sheet and opponent portrait. The supplied existing robot sprite and game cover are identity and art direction references. Create a polished 3D model turnaround sheet for the SAME chunky silver-grey robot with a softly beveled cube head, inset glossy black rectangular screen face, TWO bright red circular eyes, red ball antenna on metal spring, circular side ear caps, small mouth grille, chunky shoulder joints, articulated mechanical forearms, armored torso and boots. Add restrained bronze fasteners, dark seams and tiny scuffs, keep friendly menacing arcade expression. Front three-quarter full-body view largest at left, neutral side and back full-body views at right, all uncropped with comfortable margin, navy studio backdrop matching the hamster hero sheet. Rich dimensional game-render materials and cool rim lighting, red eye glow but readable geometry. Preserve proportions and identity of the reference robot, no other characters, no text, no watermark.
